# 知識整理アプリ UI設計（MVP）

## 1. 目的
- 入力のハードルを極限まで下げる
- 関連知識の探索と週次振り返りを「気軽に」できる

## 2. 情報設計（IA）
### 主要画面
- Inbox（未整理一覧）
- Capture（クイック入力）
- Detail（詳細）
- Review（週次振り返り）
- Settings（最小、将来用）

### ナビゲーション案
- 下部タブ: Inbox / Capture / Review / Settings
- Captureはモーダル起動でも可

## 3. 画面フロー
### 3.1 クイックキャプチャ
Inbox → Capture → Save → Inbox Detail（未整理）

### 3.2 整形フロー（外部LLM）
Inbox Detail → Prompt生成 → Promptコピー → 選択プロバイダへ移動 → 結果貼り付け → Structured Detail

### 3.3 関連知識の探索
Inbox(全体) → Detail → Related Notes → Detail

### 3.4 週次振り返り
Review → This Week → Detail
Review → Related Resurface → Detail

## 4. 画面別の仕様

### 4.1 Inbox（未整理一覧）
- セグメント: 未整理 / すべて
- 未整理はクイックキャプチャのみ表示
- 検索バー（全体検索）
- 空状態: 「最初のメモを追加しよう」CTA

### 4.2 Capture（クイック入力）
入力項目（最小）
- 1つの大きなテキスト欄（必須）
- 送信ボタンのみ
 - 画像添付（将来拡張）
 - Markdownプレビュー切替（MVP）

行動
- Save（primary）
- Cancel

### 4.3 Detail（詳細）
未整理（Inbox）状態
- Rawテキスト表示
- 「整形プロンプトを生成」ボタン
- 生成したプロンプト表示 + コピー
- 選択中の整形プロバイダへ移動（外部リンク）
- フォーマットガイド表示（貼り付け形式の説明）
- LLMの結果を貼り付ける欄（Markdown可）
- 「整形して保存」ボタン

整形済み（Structured）状態
- Title / Body
- Learned Period / Source
- Tags（チップ、推奨: 8個まで）
- Related Notes
- Backlinks（将来拡張、MVPでは非表示でも可）
- Editボタン

### 4.4 Review（週次）
- 今週の学び（直近7日）
- 関連知識のリサーフェス（数件）
- 「振り返った」トグル（MVPでは保存なしでも可）

### 4.5 Settings（最小）
- サインアウト
- 将来拡張（公開設定/エクスポート）
- 整形プロバイダ設定（ChatGPT/Claude/Gemini/カスタム）
- カスタムURL入力
- プリセットURLの表示と選択
- 出力言語設定（日本語/英語）

## 5. UXの指針（MVP）
- 入力は2タップ以内で開始できる
- ざっくり年代入力を許容
- 週次振り返りは「開くだけで価値がある」
- 整形は「外部LLMで完結」できる導線を用意

## 6. 将来拡張の余白
- 公開状態切り替えUI
- グラフビュー（知識の関係性表示）
- 期間別の成長分析
- エクスポート（Markdown / JSON）
- 画像/ファイル添付

## 7. UI文言（MVP）
**共通**
- Primary: 保存
- Secondary: キャンセル
- 編集: 編集
- 戻る: 戻る

**タブ**
- Inbox: インボックス
- Capture: メモ
- Review: 振り返り
- Settings: 設定

**Inbox**
- セグメント: 未整理 / すべて
- 検索プレースホルダ: 検索（タイトル・本文・タグ）
- 空状態（未整理）: まだメモがありません
- 空状態（未整理）補足: 右下の「メモ」から追加できます
- 空状態（全体）: まだ知識ノートがありません

**Capture**
- プレースホルダ: 雑多にメモしてOK。あとで整えます。
- ヒント: 改行で区切ってもOK
- 保存ボタン: 保存してインボックスへ
- プレビュー切替: 編集 / プレビュー

**Detail（未整理）**
- 見出し: 未整理メモ
- セクション: メモ
- ボタン: 整形プロンプトを生成
- ボタン: プロンプトをコピー
- ボタン: {選択プロバイダ}を開く
- セクション: 整形結果の貼り付け
- プレースホルダ: 整形結果をここに貼り付けてください
- ボタン: 整形して保存
- ガイド: フォーマットを見る

**Detail（整形済み）**
- 見出し: 知識ノート
- 学習時期: 学習時期
- 出典: 出典
- タグ: タグ（推奨: 8個まで）
- 関連: 関連ノート

**Review**
- 見出し: 今週の振り返り
- セクション: 今週の学び
- セクション: 関連知識のリサーフェス
- 空状態: 今週の学びはまだありません

**Settings**
- 見出し: 整形プロバイダ
- プリセット: ChatGPT（既定）
- プリセット: Claude
- プリセット: Gemini
- カスタムURL: カスタムURL
- 出力言語: 出力言語（日本語/英語）
- ボタン: サインアウト

**トースト/エラー**
- コピー完了: プロンプトをコピーしました
- 解析失敗: 整形結果を解析できませんでした。フォーマットを確認してください。
- Body欠落: Body が見つかりませんでした
- タイトル自動生成: タイトルが空のため自動生成しました
- タグ警告: タグは推奨8個までです
